# 微信群下单规则（v1）

> 适用群：早日发财有限公司
> 目的：订单一目了然，自动进 Excel，不用再手工核对

---

## 一、下单格式（每天一条）

### 第 1 行：写日期

```
【下单】2026-11-12
```

### 第 2 行起：每行一个商品

```
买家 - 商品 - 数量 - 单价 - 付款
```

**用短横线 `-` 分隔**（前后加空格更好读）

---

## 二、五个字段怎么写

| 字段 | 怎么填 | 例子 | 说明 |
|---|---|---|---|
| **买家** | 越南语原名 | `Trang Lê` | 别写「宝」「姐」这类称呼，写全名 |
| **商品** | 简称 | `十刻401晚秋` | 见下方对照表，不用写全称；表里没有的可在网站手动填品牌+商品+色号 |
| **数量** | N团 | `2团` | 一定是「数字+团」 |
| **单价** | 一团多少钱 | `295000` | 越南盾，**不写点号、不写总额** |
| **付款** | 已付X 或 全款 | `已付295000` | 不写 = 未付款 |

> 网站开单页有个「带上总价 / 已付 / 欠款」开关（每次打开默认开）。打开后每行末尾会多一段：
> `买家 - 商品 - 2团 - 295000 - 已付295000 - 总价590000 已付295000 欠295000`
> 这段是给人看的，程序只读前面 5 段，不影响导入。改单助手（方式 B）同样会带上这段。

```
【下单】2026-11-12

Trang Lê - 梵森03星月夜 - 1团 - 192000 - 已付100000

Nguyễn Dung - 十刻405 - 1团 - 295000 - 全款
```

## 四、✕ 这样发不行（会记录错误）

| ✕ 错误写法 | 问题 |
|---|---|
| `Trang Lê 十刻300克（2团401晚秋+1团402单角兽）梵森300克（1团03星月夜）- 已付290.000vnd` | 一句话混了 2 个系列、多件商品，拆不清 |
| `Kim : 彤达100%羊毛 （212色号：5团，216色号：5团）330.000vnd` | 写了色号没写单价，只能靠总额摊，容易错 |
| `1团梵森300g（02单角兽）` | 少了买家名字，不知道谁买的 |
| `Trang Lê 剩 4团十刻（单叫兽，星月夜，晚秋，小橘）` | 「4团」+4 个色号，每色几团说不清 |
| `单价写 295.000`（带点号） | 能用，但建议写 `295000` 更稳 |

## 五、发错了怎么改？

### 方式 A：作废 + 重发（推荐）

```
【下单】2026-11-12
Trang Lê - 十刻401晚秋 - 3团 - 295000 - 已付295000
Chi Chi - 十刻402 - 1团 - 295000 - 已付100000
作废 - 2026-11-12-1
Trang Lê - 十刻401晚秋 - 2团 - 295000 - 已付295000
```

- **订单号 = 日期-序号**
- 序号 = 这条消息里的**第几行**（从 1 数）
- 上例中 `2026-11-12-1` 就是第 1 行（3 团那条），作废后重发 2 团的

### 方式 B：引用原消息 + 回复「更正」

```
长按原来那条 → 引用 → 回复：

更正 - 3团 - 295000 - 已付295000
```

**日期会自动沿用原日期**，不会变成今天。

例如引用 11-08 的单子今天改，记录还是 11-08。

网站「改单助手」也能生成这行：填数量、单价，选未付 / 已付 / 全款，会顺带算出总价和欠多少：

```
更正 - 2团 - 295000 - 全款 - 总价590000 已付590000 欠0
```

### ✕ 千万别用「撤回」

微信撤回后只保留一句「xx 撤回了一条消息」，**原内容直接被删除**。

程序读不到原来写了什么，也无法知道改的是哪一条。

**要改就用「作废」或「引用更正」。**

## 六、日期怎么算

| 你做的操作 | 记录的日期 |
|---|---|
| 正常发 `【下单】2026-11-12` | 2026-11-12 |
| 作废 + 重发（同一条消息） | 消息里的日期 |
| **引用 11-08 的旧消息回复「更正」** | **2026-11-08（原日期）** |
| 引用但原消息已被删 | 今天的日期（会提示 ⚠） |
| 单独发「更正」但没引用 | 无法处理 ✕ |

## 七、常见问题

**Q：同一天发两条【下单】可以吗？**

可以。两条都会记录，日期相同，不冲突。

**Q：一批货分几次付款怎么写？**

每次收到钱就引用原单，回复：

```
更正 - 2团 - 295000 - 已付590000
```

把「已付」改成累计已付金额。

**Q：客户退货怎么办？**

作废那条，然后告诉我一声「退货」。我在 Excel 里用负数数量处理。

**Q：商品表里没有怎么办？**

在网站开单页点商品 → 切到「手动输入」，填**品牌 / 商品 / 色号颜色**，照样能生成文案发群。

同时告诉我一声，我在【商品资料】里加，以后就能直接从列表选（简称对得上，导入不会报「商品未匹配」）。

**Q：12团装那种怎么算？**

`羊绒43` 是 12 团装，按**套**卖：

```
Thuỳ Dương - 羊绒43 - 12团 - 1135000 - 已付250000
```

金额 = **1 套 × 1,135,000**，不是 12 × 1,135,000。

系统会自动识别，你照常写 12团 就行。

## 九、每天流程

1. **发单**：按上面格式发【下单】消息
2. **改单**：作废 + 重发，或引用 + 更正
3. **导入**：发完跟我说「导入」
4. **核对**：我导出核对清单，你确认后定稿
